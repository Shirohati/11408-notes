# 考研词汇学习

一个纯前端单词记忆工具，帮助考研复习中攻克顽固词汇。

## 使用方式

直接用浏览器打开 `index.html` 即可，无需安装任何东西。所有数据保存在浏览器本地（localStorage）。

## 功能

| 功能 | 说明 |
|------|------|
| 隐藏翻译 | 默认中文被遮住，点击单词或翻译区域切换显示 |
| 不认识 +1 | 悬停卡片后出现，点击计数 +1，标记为不认识 |
| 认识标记 | 悬停点击「认识」，单词左侧出现绿色边框，计入已认识 |
| 筛选 | 全部 / 不认识 / 已认识 |
| 排序 | 默认 / 按不认识次数降序 |
| 自动隐藏 | 点击一个词时自动收起其他词的翻译 |
| 导出备份 | 下载 JSON 备份文件 |
| 导入备份 | 导入备份，可选「合并」或「替换」 |

## 加词

将新词发给开发者，由我修改 `js/words.js` 文件。数据迁移会自动保留已有学习记录。

## 备份与恢复

**导出：** 点击「导出备份」按钮，下载 `.json` 文件。

**导入：** 点击「导入备份」，选择备份文件，弹窗选择：
- **合并：** 保留当前认识状态，只补充备份中有而本地没有的词
- **替换：** 完全用备份数据覆盖当前所有数据

**建议定期导出备份，防止数据丢失。**

## 数据安全

- 所有数据存储在浏览器 localStorage 中
- 添加新词时：旧数据逐索引保留，新词自动分配空状态，不会丢失已有记录
- 导入时支持合并模式，不会意外覆盖已有学习记录
- 数据损坏时自动降级重建，不会覆盖旧数据
