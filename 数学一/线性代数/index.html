    线性代数 · 常用公式与定理¶

    一、行列式¶

    行列式性质¶

    • \(|A^T| = |A|\)
    • \(|kA| = k^n|A|\)
    • \(|AB| = |A||B|\)
    • \(|A^{-1}| = \dfrac1{|A|}\)
    • \(|A^*| = |A|^{n-1}\)
    • \(|A| = \prod_{i=1}^n \lambda_i\)（特征值乘积）
    • 两行互换 → 变号；某行乘 \(k\) → 值乘 \(k\)；两行成比例 → 为 \(0\)
    • 某行加上另一行的 \(k\) 倍 → 值不变

    特殊行列式¶

    类型 值
    上/下三角 主对角线乘积
    对角矩阵 \(\operatorname{diag}(d_1,\dots,d_n)\) \(d_1d_2\cdots d_n\)
    范德蒙 \(\begin{vmatrix}1&1&\cdots&1\\x_1&x_2&\cdots&x_n\\\vdots&\vdots&&\vdots\\x_1^{n-1}&x_2^{n-1}&\cdots&x_n^{n-1}\end{vmatrix}\) \(\displaystyle\prod_{1\le j<i\le n}(x_i-x_j)\)
    反对角线行列式 \((-1)^{\frac{n(n-1)}2}\prod a_i\)
    \(\begin{vmatrix}A&B\\C&D\end{vmatrix}\)（分块） $

    二、矩阵¶

    矩阵运算¶

    • \((A^T)^T = A\)，\((kA)^T = kA^T\)，\((AB)^T = B^TA^T\)，\((A+B)^T = A^T+B^T\)
    • \((AB)^{-1}=B^{-1}A^{-1}\)，\((A^T)^{-1}=(A^{-1})^T\)
    • \((A^*)^{-1}=(A^{-1})^*=\dfrac{A}{|A|}\)（\(A\) 可逆时）

    伴随矩阵¶

    • \(AA^* = A^*A = |A|I\)
    • \(A^* = |A|A^{-1}\)（\(A\) 可逆）
    • \((A^*)^* = |A|^{n-2}A\)（\(n\ge2\)）
    • \(|A^*| = |A|^{n-1}\)

    逆矩阵公式¶

    • \(A_{2\times2}^{-1} = \dfrac1{ad-bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}\)
    • 分块对角：\(\begin{pmatrix}A&\\&B\end{pmatrix}^{-1}=\begin{pmatrix}A^{-1}&\\&B^{-1}\end{pmatrix}\)
    • 分块反对角：\(\begin{pmatrix}&A\\B&\end{pmatrix}^{-1}=\begin{pmatrix}&B^{-1}\\A^{-1}&\end{pmatrix}\)

    特殊矩阵¶

    矩阵 定义 性质
    对称矩阵 \(A^T=A\) 特征值全为实数，不同特征值特征向量正交
    反对称矩阵 \(A^T=-A\) 主对角元为 \(0\)
    正交矩阵 \(Q^TQ=I\) \(Q^{-1}=Q^T\)，行/列向量两两正交单位化，\(\|Qx\|=\|x\|\)
    幂等矩阵 \(A^2=A\) 特征值只能为 \(0\) 或 \(1\)
    幂零矩阵 \(A^k=0\) 特征值全为 \(0\)
    正定矩阵 \(x^TAx>0\) 所有特征值 \(>0\)，顺序主子式 \(>0\)

    矩阵的秩¶

    • \(r(A) \le \min(m,n)\)
    • \(r(A)=r(A^T)=r(AA^T)=r(A^TA)\)
    • \(r(A\pm B) \le r(A)+r(B)\)
    • \(r(AB) \le \min(r(A),r(B))\)
    • \(r(A)+r(B)-n \le r(AB)\)（Sylvester）
    • \(A_{m\times n},B_{n\times s},AB=0 \Rightarrow r(A)+r(B) \le n\)
    • \(r(A)=1\) 的充要条件：\(A\) 可写成 \(\alpha\beta^T\)（\(\alpha,\beta\) 为非零列向量）
    • 初等变换不改变秩

    常用结论¶

    • \(A\) 可逆 \(\Leftrightarrow |A|\neq0 \Leftrightarrow r(A)=n \Leftrightarrow A\) 满秩 \(\Leftrightarrow A\) 特征值全非零 \(\Leftrightarrow Ax=0\) 只有零解
    • \(AB=0\)，\(A\) 列满秩 \(\Rightarrow B=0\)
    • \(AB=I\)，则 \(A\) 左逆为 \(B\)，\(B\) 右逆为 \(A\)

    三、向量¶

    线性相关判断¶

    • \(n+1\) 个 \(n\) 维向量必线性相关
    • 含零向量的向量组必线性相关
    • 部分相关 ⇒ 整体相关；整体无关 ⇒ 部分无关
    • 若 \(\alpha_1,\dots,\alpha_s\) 线性无关，\(\beta\) 不能由它们线性表示，则 \(\alpha_1,\dots,\alpha_s,\beta\) 线性无关
    • \(\alpha_1,\dots,\alpha_s\) 线性无关 \(\Leftrightarrow\) 只有零解 \(\Leftrightarrow r(\alpha_1,\dots,\alpha_s)=s\)

    极大无关组与秩¶

    • 向量组的秩 = 向量组张成空间的维数
    • 矩阵的秩 = 行向量组的秩 = 列向量组的秩
    • 等价向量组秩相等，反之不成立

    施密特正交化¶

    给定 \(\alpha_1,\alpha_2,\dots,\alpha_s\)：

    \[ \begin{aligned} \beta_1 &= \alpha_1 \\ \beta_2 &= \alpha_2 - \frac{(\alpha_2,\beta_1)}{(\beta_1,\beta_1)}\beta_1 \\ \beta_3 &= \alpha_3 - \frac{(\alpha_3,\beta_1)}{(\beta_1,\beta_1)}\beta_1 - \frac{(\alpha_3,\beta_2)}{(\beta_2,\beta_2)}\beta_2 \end{aligned} \]

    再单位化：\(\eta_i = \dfrac{\beta_i}{\|\beta_i\|}\)

    四、线性方程组¶

    有解判定¶

    方程组 有解条件 解的情况
    \(Ax=0\)（齐次） 恒有解 \(r(A)=n\) 仅有零解；\(r(A)<n\) 有无穷多解
    \(Ax=b\)（非齐次） \(r(A)=r(A\|b)\) \(r(A)=r=n\) 唯一解；\(r(A)=r<n\) 无穷多解

    解的结构¶

    • 齐次：基础解系含 \(n-r(A)\) 个线性无关的解，通解为 \(\sum_{i=1}^{n-r} k_i\xi_i\)
    • 非齐次：通解 = 特解 + 齐次通解
    • 两个非齐次解之差是齐次解
    • 非齐次解之和 \(\,\times\,1/2\,\) 也是非齐次解（系数和为1时）

    克拉默法则¶

    \(n\) 个方程 \(n\) 个未知数，\(|A|\neq0\) 时： $\(x_j = \frac{|A_j|}{|A|}\)$ \(A_j\) 是 \(A\) 的第 \(j\) 列换成 \(b\)

    五、特征值与特征向量¶

    性质¶

    • \(\displaystyle\sum_{i=1}^n\lambda_i = \operatorname{tr}(A)\)
    • \(\displaystyle\prod_{i=1}^n\lambda_i = |A|\)
    • 不同特征值对应的特征向量线性无关
    • \(k\) 重特征值至多有 \(k\) 个线性无关的特征向量
    • \(A\) 与 \(A^T\) 特征值相同
    • 实对称矩阵不同特征值的特征向量正交

    特征值关系¶

    矩阵 特征值 特征向量
    \(A\) \(\lambda\) \(x\)
    \(kA\) \(k\lambda\) \(x\)
    \(A^k\) \(\lambda^k\) \(x\)
    \(A^{-1}\) \(\dfrac1\lambda\) \(x\)
    \(A^*\) $\dfrac{ A
    \(f(A)\) \(f(\lambda)\) \(x\)
    \(P^{-1}AP\) \(\lambda\) \(P^{-1}x\)

    相似对角化¶

    \(A_{n\times n}\) 可对角化 \(\Leftrightarrow A\) 有 \(n\) 个线性无关的特征向量 \(\Leftrightarrow\) 每个 \(k\) 重特征值恰好有 \(k\) 个线性无关的特征向量 \(\Leftrightarrow\) 几何重数 \(=\) 代数重数

    实对称矩阵¶

    • 必可对角化（正交对角化）
    • 存在正交矩阵 \(Q\) 使 \(Q^TAQ = \Lambda\)
    • 不同特征值对应的特征向量正交
    • 特征值全为实数

    六、二次型¶

    基本概念¶

    $\(f(x_1,\dots,x_n) = x^TAx\)$ 其中 \(A\) 为实对称矩阵（\(A\) 即二次型矩阵）

    标准形 & 规范形¶

    • 标准形：\(d_1y_1^2 + d_2y_2^2 + \cdots + d_ny_n^2\)
    • 规范形：\(y_1^2+\cdots+y_p^2 - y_{p+1}^2 - \cdots - y_r^2\)（\(p\) 正惯性指数，\(r\) 秩）
    • 惯性定理：正负惯性指数唯一

    正定矩阵判定¶

    \(A_{n\times n}\) 正定 \(\Leftrightarrow\)：

    条件 说明
    ① 所有特征值 \(>0\)
    ② 各阶顺序主子式 \(>0\)（赫尔维茨定理）
    ③ \(A\) 与单位矩阵合同
    ④ 存在可逆 \(P\) 使 \(A=P^TP\)
    ⑤ 对任意 \(x\neq0\)，\(x^TAx>0\)

    负定：顺序主子式 \(<0\)（奇数阶）、\(>0\)（偶数阶）

    配方法化标准形¶

    1. 若 \(a_{11}\neq0\)：把所有含 \(x_1\) 项集中配方
    2. 若 \(a_{11}=0\) 但 \(a_{ii}\neq0\)：从 \(x_i\) 开始配方
    3. 若所有 \(a_{ii}=0\)：令 \(\begin{cases}x_i=y_i+y_j\\x_j=y_i-y_j\end{cases}\) 出现平方项

    合同¶

    • \(A \cong C^TBC\)（\(C\) 可逆），\(A,B\) 合同
    • 合同 \(\Rightarrow\) 秩相等，正负惯性指数相同
    • 相似 \(\Rightarrow\) 合同（对实对称矩阵）

    七、重要定理归纳¶

    秩的等式与不等式¶

    • \(r(A)=r(A^TA)\)（实数域）
    • \(r\begin{pmatrix}A&0\\0&B\end{pmatrix}=r(A)+r(B)\)
    • \(r\begin{pmatrix}A&C\\0&B\end{pmatrix}\ge r(A)+r(B)\)
    • \(r(A-B) \ge |r(A)-r(B)|\)

    等价、相似、合同关系¶

    关系 定义式 不变性质
    等价 \(B=PAQ\)（\(P,Q\) 可逆） 秩
    相似 \(B=P^{-1}AP\)（\(P\) 可逆） 秩、特征值、行列式、迹、可逆性、若尔当形
    合同 \(B=C^TAC\)（\(C\) 可逆） 秩、对称性、正负惯性指数

    Cayley-Hamilton 定理¶

    \(A\) 的特征多项式为 \(f(\lambda)=|\lambda I-A|\)，则 \(f(A)=0\)

    若尔当标准形¶

    任意 \(n\) 阶矩阵 \(A\) 相似于若尔当形矩阵 \(J = \begin{pmatrix}J_1&&\\&\ddots&\\&&J_s\end{pmatrix}\)， 其中 \(J_i = \begin{pmatrix}\lambda_i&1&&\\&\lambda_i&\ddots&\\&&\ddots&1\\&&&\lambda_i\end{pmatrix}\)

    八、常用二级结论¶

    • \(AB = I \Leftrightarrow BA = I\)（对方阵）
    • \(A, B\) 均为 \(n\) 阶矩阵，\(AB=0\)，则 \(r(A)+r(B)\le n\)，且 \(r(A), r(B)\) 至少有一个 \(\le n/2\)
    • 若 \(A\) 可逆，则 \(r(AB)=r(B)\)；若 \(B\) 可逆，则 \(r(AB)=r(A)\)
    • \(r(A)=r \Leftrightarrow A\) 可分解为 \(A=BC\)，其中 \(B\) 列满秩 \(C\) 行满秩
    • \(\alpha,\beta\) 为 \(n\) 维列向量，则 \(r(\alpha\beta^T)=1\)（非零时）
    • \(\alpha\beta^T\) 的特征值为 \(\beta^T\alpha\) 和 \(0\)（\(n-1\) 重）
    • \(A\) 为幂等矩阵（\(A^2=A\)），则 \(A\) 可对角化，特征值只有 \(0,1\)
    • \(A\) 为对合矩阵（\(A^2=I\)），则 \(A\) 可对角化，特征值只有 \(\pm1\)
    • \(A\) 正交相似于对角矩阵 \(\Leftrightarrow A\) 为实对称矩阵
    • 实对称矩阵 \(A\) 正定 \(\Leftrightarrow\) 各阶顺序主子式 \(>0\)
